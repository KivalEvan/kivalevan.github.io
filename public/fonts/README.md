# Self-hosted fonts

The site serves Latin WOFF2 subsets for these typefaces:

- Big Shoulders Display 800
- Space Mono 400 and 700
- League Gothic 400

All families use the SIL Open Font License 1.1. The corresponding copyright notices and full license texts are in `public/fonts/licenses`.

The font files and license metadata come from the Google Fonts repository and Google Fonts delivery service.
